# Communication API E2E tests

These tests reproduce the feedback, comment, and vote lifecycle covered by the Go and
PHP SDK E2E suites:

1. List existing feedbacks.
2. Create and retrieve a feedback.
3. Update the feedback and its status.
4. Create, retrieve, update, and delete a comment.
5. Add and remove a user vote.
6. Delete the feedback and clean up after failures.

The lifecycle is executed with all four method styles generated by the C# SDK:
synchronous, synchronous `WithHttpInfo`, asynchronous, and asynchronous
`WithHttpInfo`. This covers all 48 generated Communication feedback methods. The
`ErrorApi.ReturnInternalServerError*` methods are intentionally excluded because they
are test endpoints whose successful response is HTTP 500.

The `WithHttpInfo` and `WithHttpInfoAsync` styles are also executed as dedicated raw
response stories. They retain the generated `ApiResponse` wrapper, parse `RawContent`
as JSON, and verify the required JSON keys for feedback lists, feedbacks, comments,
and votes. Void operations must retain the raw response wrapper as well. After each
feedback, status, and comment update, the resource is fetched again and the updated
fields are checked. Comment responses must contain a non-zero `CreatedAt` value.

The test changes live Communication API data and therefore runs only when explicitly
enabled:

```bash
SAASUS_E2E=true \
SAASUS_SAAS_ID=... \
SAASUS_API_KEY=... \
SAASUS_SECRET_KEY=... \
TEST_USER_ID=... \
dotnet test tests/SaaSusSdk.Tests.csproj --filter 'Category=E2E'
```

Use a dedicated SaaSus environment. `TEST_USER_ID` defaults to the all-zero UUID used
by the Go and PHP suites, and `SAASUS_API_URL_BASE` can override the default API host.
The setup and cleanup hooks remove the feedback created by a story, including after a
failed step.

Snapshots use the same shared layout as the Go and PHP suites. Capture/compare/report
commands can be run through the dedicated snapshot test; the module is forced to
`communication` so `E2E_SNAPSHOT_MODULE` is not required:

```bash
SAASUS_E2E=true E2E_SNAPSHOT_MODE=capture E2E_SNAPSHOT_TAG=v1.0.0-8-gbcd96cd \
dotnet test tests/SaaSusSdk.Tests.csproj --filter 'Category=Snapshot&Module=communication'

E2E_SNAPSHOT_MODE=compare E2E_SNAPSHOT_COMPARISON_MODE=manual \
E2E_SNAPSHOT_OLD_TAG=v1.0.0-8-gbcd96cd E2E_SNAPSHOT_NEW_TAG=communication-v2 \
dotnet test tests/SaaSusSdk.Tests.csproj --filter 'Category=Snapshot&Module=communication'
```
